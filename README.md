# flipkart-dashboard-project

This project contains a Tableau dashboard built on Flipkart product review data, along with the raw dataset, cleaned dataset, and documentation of the cleaning process.

## Project Structure

```text
flipkart-dashboard-project/
├── data/
│   ├── raw/
│   │   └── flipkart_product.csv
│   └── cleaned/
│       └── flipkart_product_cleaned.csv
├── dashboard/
│   └── flipkart_dashboard.twb
├── docs/
│   └── cleaning_steps.md
└── README.md
```

## Contents

- `data/raw/flipkart_product.csv`: Original source dataset.
- `data/cleaned/flipkart_product_cleaned.csv`: Cleaned dataset used for dashboarding and analysis.
- `dashboard/flipkart_dashboard.twb`: Tableau workbook for the Flipkart dashboard.
- `docs/cleaning_steps.md`: Summary of the data-cleaning process.
